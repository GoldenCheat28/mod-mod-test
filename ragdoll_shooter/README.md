# Ragdoll Shooter: тестовая сцена

Godot **4.7**, физика **Jolt**. Открой папку `ragdoll_shooter` в Godot и нажми F5.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | ходьба |
| Shift | бег |
| Ctrl / C | присед |
| Space | прыжок (с «койот-таймом» и буфером нажатия) |
| ЛКМ | огонь (автомат, 650 выстр/мин) |
| ПКМ | прицеливание |
| R | перезарядка |
| **Держи E** | взять предмет или тело; отпустил — уронил |
| ЛКМ с предметом | бросить |
| Колесо | держать ближе/дальше |
| B | заспавнить бота перед собой |
| Esc / клик | отпустить / захватить мышь |
| F1 | скрыть подсказку |

Клавиши регистрируются в `autoload/game_input.gd`. Если переназначишь их в
Project Settings → Input Map, код твои настройки не тронет.

## Что есть

- **Уровень** из CSG-блоков с сеткой-прототипом как в Unreal (`shaders/grid.gdshaderinc`).
  Белая стена для теста крови, тёмная комната (видно свет вспышки), пандус с платформой,
  блоки для прыжков (0,5 / 1 / 1,25 м), укрытия.
- **Игрок-капсула** (`scripts/player.gd`): ускорение/инерция, покачивание камеры,
  просадка при приземлении, наклон при стрейфе, толкание предметов.
- **Оружие-брусок** (`scenes/weapon.tscn`, `scripts/weapon.gd`):
  - вспышка (процедурная «звезда» + 2 языка пламени, ~30 мс) и короткий свет;
  - дымок из ствола, гильзы с физикой и звоном об пол;
  - отдача на пружинах (оружие + камера, прицел частично возвращается сам);
  - инерция от мыши, покачивание при ходьбе, поза бега;
  - ствол отводится, если упёрся в стену; разброс зависит от движения и прыжка;
  - трассер каждый 3-й выстрел, перезарядка с анимацией магазина.
- **Попадания** (`autoload/fx.gd`): дырки-декали, крошка бетона, пыль, искры (на металле —
  много), щепки от дерева. Частицы мягкие (proximity fade), без мерцания.
- **Кровь**: брызги каплями, кровяная взвесь, рана-декаль на кости (едет с телом),
  кляксы на стенах **через шейдер**, которые **стекают и засыхают** (`shaders/prototype_grid.gdshader`
  + `autoload/blood_walls.gd`).
- **Бот** (`scripts/bot.gd`) из 11 капсул: бродит, вздрагивает от попаданий. Урон по частям
  тела (голова ×4, руки/ноги меньше). Пуля между ног пролетает мимо.
- **Регдолл** (`scripts/ragdoll.gd`): капсулы на суставах Generic6DOF с реальными пределами
  (колени гнутся только назад, локти только вперёд). Тело можно тащить за руку или ногу на **E**.
- **Предметы** (`scenes/props/`): ящики, большой ящик (35 кг, тяжело тащить), бочки,
  доска, мячи, банки, шлакоблоки. У каждого `surface` для эффектов и звука удара.
- **HUD**: прицел (расходится по реальному разбросу), хитмаркер (жёлтый — голова, красный — убийство),
  иконка руки (открытая при наведении, сжатая при удержании), патроны, FPS.
- **Звуки-заглушки** генерируются в коде (`autoload/sfx.gd`), файлы не нужны.

## Как подставить свою иконку руки

Выдели узел `HUD/Root` в `scenes/hud.tscn` и перетащи свои картинки в `Hand Open` и `Hand Closed`.
Если у тебя одна иконка, очисти `Hand Closed`: тогда открытая рука будет «сжиматься» анимацией.

## Слои физики

| № | Имя | Кто |
|---|---|---|
| 1 | world | уровень |
| 2 | player | игрок |
| 3 | bot | живые боты |
| 4 | props | предметы |
| 5 | ragdoll | части регдолла |
| 6 | shells | гильзы (не мешают игроку) |

Слои рендера: 1 — мир, 2 — персонажи (на них рисуются раны), 3 — оружие в руках.
