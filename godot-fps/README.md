# FPS Shooter (Godot 4.7)

Открой папку `godot-fps/` в Godot и нажми F5.
WASD — движение, Shift — бег, Пробел — прыжок, ЛКМ — огонь, Esc — освободить мышь.

- Своя карта: сделай сцену в `maps/`, перетащи её в `map_scene` у узла Main.
- Анимации врага: добавь `AnimationPlayer` с клипами `idle`/`run`/`die` (например, из Mixamo).
- 165 FPS: VSync выключен, лимит 165, физика 165 Гц (project.godot).
