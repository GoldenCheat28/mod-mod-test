# Карта в Blockbench

1. Blockbench → File → Open Model → `arena.bbmodel` (формат Generic Model, 1 м = 16 единиц).
2. Редактируй кубы, перекрашивай `palette.png` (каждый квадрат 16×16 — отдельный цвет).
3. File → Export → **Export glTF Model** → сохрани как `godot-fps/maps/map.glb`.
4. Запусти игру — карта подхватится автоматически (если `map.glb` есть, арена из кода не создаётся).

Имена кубов (по префиксу) задают поведение:
- `spawn_player`, `spawn_enemy_*` — точки появления (сам куб в игре исчезает)
- `light_*` — лампа (светящаяся панель + источник света)
- `prop_*` — физический предмет (двигается, можно толкать/стрелять)
- `nocol_*` — без коллизии (декор)
- всё остальное — статичная геометрия с коллизией, по ней же строится навигация ботов

Заново сгенерировать исходную карту: `python3 tools/gen_arena_bbmodel.py`.
