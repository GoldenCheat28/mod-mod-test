# Карта (склад 80×60 м) и Blockbench

Карта описана в `layout.json` (читает игра) и `arena.bbmodel` (открывается в Blockbench).
Оба файла генерирует `python3 tools/gen_arena_bbmodel.py` — правь расстановку в этом скрипте.

## Своя карта через Blockbench
1. Blockbench → File → Open Model → `arena.bbmodel` (Generic Model, 1 м = 16 единиц).
2. Редактируй кубы, перекрашивай `palette.png` (каждый квадрат 16×16 — отдельный материал).
3. File → Export → **Export glTF Model** → сохрани как `godot-fps/maps/map.glb`.
4. Запусти игру — если есть `map.glb`, он загрузится вместо встроенной карты.

## Имена кубов задают поведение (по префиксу)
- `spawn_player`, `spawn_enemy_*` — точки появления (сам куб исчезает)
- `light_*` — лампа (светящаяся панель + источник света)
- `prop_*` — физический предмет (двигается, можно толкать и стрелять)
- `nocol_*` — декор без коллизии
- всё остальное — статичная геометрия с коллизией; по ней строится навигация ботов
