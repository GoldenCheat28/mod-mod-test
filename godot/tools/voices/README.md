# Голоса ботов

Фразы озвучены синтезатором речи [Piper](https://github.com/rhasspy/piper) (бесплатный, работает офлайн).
За основу взяты три русских мужских голоса: denis, dmitri и ruslan.

- **50 голосов** (`assets/sounds/voices/v01` … `v50`). Каждый — это одна из трёх основ, у которой изменены:
  - высота голоса;
  - темп речи;
  - манера: чистый, хриплый, глухой, гнусавый, дрожащий, грубый, прокуренный или тонкий.

  Описание каждого голоса лежит в `voices.json`, в поле `name`.
- **20 ситуаций** заданы в `lines.json`, в каждой 10–12 вариантов фраз:

  | Ситуация | Что это |
  |---|---|
  | `greet` | приветствие |
  | `greet_reply` | ответ на приветствие |
  | `how_are_you` | «как жизнь» |
  | `answer_life` | ответ про жизнь |
  | `brush_off` | отшивание |
  | `anger` | злость |
  | `tease` | подкол |
  | `tease_back` | огрызание |
  | `make_peace` | примирение |
  | `smoke` | курение |
  | `thinking` | размышления вслух |
  | `story` | истории |
  | `react_story` | реакция на рассказ |
  | `bye` | прощание |
  | `scared` | испуг (ствол) |
  | `saw_body` | увидел труп |
  | `player_face` | игрок встал вплотную |
  | `bar_drunk` | бар и выпивка |
  | `gamble` | рулетка и азарт |
  | `money_work` | деньги и работа |

- **Кто что говорит.** Каждый голос произносит свои 3–5 случайных вариантов из каждой ситуации. Так у разных ботов разные фразы, а архив не раздувается.
- **Как боты разговаривают.** Сценарии описаны в `scripts/bots/chatter.gd` → `_script()`:
  - «как жизнь»;
  - история и ответная история;
  - про деньги;
  - перекур вдвоём;
  - «привет — отвали — злость»;
  - подкол — огрызание — мир или ругань.
- **Твои записи.** Фразы из `assets/sounds/voice/*.wav` остались. Примерно каждый восьмой бот говорит ими там, где для ситуации есть твоя запись.

## Перегенерировать

```
pip install piper-tts soundfile scipy numpy
# модели ru_RU-denis-medium.onnx, ru_RU-dmitri-medium.onnx, ru_RU-ruslan-medium.onnx (+ .onnx.json)
# с https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU
python3 generate_voices.py --models <папка с моделями>
```

Уже готовые файлы скрипт не перезаписывает. После правки фразы в `lines.json` удали старые `.ogg` этой ситуации и запусти скрипт заново.
