# Модели игры для Blockbench

Всё здесь выгружено прямо из кода игры скриптом `godot/tests/export_blockbench.gd`.
В каждой папке лежит:

- **`*.bbmodel`** — проект Blockbench. Открывается через `File → Open Model` или перетаскиванием файла в окно.
  Внутри уже есть меши, разбитые на группы, и встроенные текстуры. У сигареты есть ещё и анимация.
- **`*.obj` + `*.mtl` + `textures/`** — запасной вариант. Подходит и для других программ, например Blender.
  В Blockbench его открывают так: `File → New → Generic Model`, затем `File → Import → OBJ Model`.

## Масштаб

- **Оружие и сигарета:** 1 единица Blockbench = **1 см**. Пистолет около 26 единиц в длину, АКМ около 85, снайперская винтовка около 108.
- **Карта:** 16 единиц = **1 м**, то есть одна клетка сетки Blockbench — это метр.
- **OBJ-файлы** записаны в метрах. При импорте в Blockbench укажи масштаб 100 для оружия и 16 для карты.

## Сигарета и анимация

1. Открой `03_Сигарета/cigarette_smoking.bbmodel`.
2. Справа вверху переключись на **Animate** и выбери анимацию **«курение»** (10,6 с).
3. Что происходит: руки поднимаются, зажигалка поджигает сигарету, затяжка, рука опускается, вторая затяжка, окурок отбрасывается.

Группы, которые двигаются: `Правая_рука` и `Сигарета` внутри неё (`бумага`, `огонёк`, `пепел_у_огонька`), а также `Левая_рука_зажигалка` с `пламя_зажигалки`.
Пламя показывается и прячется ключами масштаба 0/1.

Это вид от первого лица. Глаз (камера) находится в точке **(0, 50, 35)**, взгляд направлен вдоль −Z.
Дым — это частицы, поэтому его в модели нет. Укорачивание сигареты при затяжке тоже не выгружено, двигается только огонёк.

## Названия частей

Детали без собственного имени в игре подписаны по материалу и форме, например «сталь (цилиндр)» или «дерево_АКМ (форма)».
Подвижные части оружия названы так, как их зовёт код игры: `Slide` (затвор), `Mag` (магазин), `Trigger` (спуск), `Barrels` (стволы обреза), `Pump` (цевьё), `BoltHandle` (рукоять затвора), `Scope` (прицел), у револьвера — `Cylinder_барабан`, `Crane_откидной_узел`, `Hammer_курок`.
**Эти имена лучше не менять** — по ним игра их двигает.

## Текстуры

- Цвета взяты из игры.
- У «шумных» материалов (бетон, дерево, полимер) в игре текстура проецируется на модель сама (triplanar). Здесь она разложена по граням так, чтобы выглядело похоже.
- Перерисовывать можно во вкладке **Paint**.

## Как вернуть правки в игру

Сохрани изменённый `.bbmodel` и закоммить его в эту же папку, затем напиши мне, что поменял.
Я подключу модель в игру вместо той, что строится из кода. Масштаб и имена подвижных частей я знаю.

## Обновить выгрузку

Если модели в коде поменяются, выгрузку можно запустить заново (нужен Godot 4.7):

```
godot --path godot res://tests/export_blockbench.tscn -- <папка> [weapons,cigarette,map]
```
